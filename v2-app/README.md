# Fan OS V2 — visual-first

Nova implementação em React Native + Expo, pensada para validar visualmente cada módulo antes de ligar a lógica real.

## Ver rapidamente
1. Instalar Node.js 22.
2. Nesta pasta: npm install
3. Executar: npm run web
4. Abrir o endereço indicado pelo Expo no browser.

## Telemóvel
Com o servidor em execução, usar Expo Go e ler o QR apresentado pelo Expo.

## Método de trabalho
Aprovar visualmente: Login → Clube → Home → Jogos → Bilhete/QR → Wallet → Perfil.
Só depois ligar API, autenticação, pagamentos, push e restantes integrações.
